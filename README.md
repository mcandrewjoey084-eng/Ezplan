EzPlan 📚

A simple homework planner built for high-school students.

EzPlan is a student-focused homework planning website designed to make staying organized easier. It allows students to add assignments, specify their class and due date, and mark work as completed.

✨ Features
Add homework assignments
Organize assignments by class
Set due dates
Mark assignments as completed
Remove completed or unwanted assignments
Automatically save assignments in the browser
Simple, clean, student-friendly design
Works on desktop and mobile devices
🎯 Purpose

School can become difficult to manage when assignments, projects, and deadlines are spread across different platforms. EzPlan was created to provide students with one simple place to keep track of their work and stay organized.

🛠️ Built With
HTML
CSS
JavaScript
Browser Local Storage
🚀 Getting Started

No installation is required.

Simply open index.html in a web browser to use EzPlan.
